# 01. Programming Fundamentals

This folder focuses on the basic building blocks of programming.

## Topics

- variables
- data types
- operators
- conditional statements
- loops
- functions
- input/output
- debugging basics

## Practice questions

1. Write a program to print the numbers from 1 to 20.
2. Check whether a number is even or odd.
3. Find the sum of numbers from 1 to 100.
4. Write a function to calculate the area of a rectangle.
5. Create a simple calculator.

## Challenge questions

- Find the largest number in a list.
- Check if a year is a leap year.
- Print a multiplication table.
- Count how many vowels appear in a word.

## Tips

- Be careful with loops.
- Test small sample values first.
- Practice writing functions to make code cleaner.
