# 02. Arrays and Strings

This section focuses on working with collections of data.

## Topics

- arrays or lists
- indexing
- iteration
- string operations
- searching and counting
- reversing values

## Practice questions

1. Reverse an array.
2. Find the maximum number in an array.
3. Count the number of vowels in a string.
4. Check if a string is a palindrome.
5. Print every element in a list.

## Challenge questions

- Remove duplicate elements from a list.
- Find the second largest number.
- Count repeated words in a sentence.
- Sort names alphabetically.

## Tips

- Understand indexing before solving harder problems.
- Practice with both numbers and strings.
- Write simple examples by hand before coding.
