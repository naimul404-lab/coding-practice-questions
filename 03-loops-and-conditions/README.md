# 03. Loops and Conditions

This section helps you practice decision-making and repetition.

## Topics

- if/else conditions
- nested conditions
- for loops
- while loops
- break and continue

## Practice questions

1. Print all even numbers from 1 to 50.
2. Find the sum of numbers entered by a user.
3. Print a triangle pattern.
4. Check whether a number is prime.
5. Calculate factorial using a loop.

## Challenge questions

- Print a pyramid pattern.
- Count how many numbers are divisible by 3 from 1 to 100.
- Make a simple login check using conditions.

## Tips

- Understand where loops should stop.
- Always test a minimal case first.
- Use conditions carefully to avoid mistakes.
