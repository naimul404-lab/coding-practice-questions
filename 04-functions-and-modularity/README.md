# 04. Functions and Modularity

This section helps you write reusable and organized code.

## Topics

- function definition
- parameters and arguments
- return values
- modular code
- calling functions properly

## Practice questions

1. Write a function to add two numbers.
2. Write a function to check if a number is odd or even.
3. Write a function that returns the square of a number.
4. Use functions to calculate the average of a list.
5. Create a calculator using separate functions.

## Challenge questions

- Write a function to calculate the factorial.
- Write a function to find the largest item in a list.
- Build a mini library of reusable math functions.

## Tips

- Keep every function focused on one task.
- Give functions meaningful names.
- Return values when useful.
