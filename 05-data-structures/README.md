# 05. Data Structures

This section focuses on common structures used in programming.

## Topics

- arrays
- lists
- stacks
- queues
- sets
- maps
- hash tables
- linked lists

## Practice questions

1. Use a stack to reverse a string.
2. Use a queue to process tasks in order.
3. Count the frequency of items in a list.
4. Build a dictionary of student records.
5. Find the first repeated item in a list.

## Challenge questions

- Create a simple queue implementation.
- Use a stack to check for balanced brackets.
- Store student names and scores in a map.

## Tips

- Know when to use arrays, maps, and sets.
- Understand the difference between order and lookup speed.
