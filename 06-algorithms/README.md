# 06. Algorithms

This section helps you understand how to solve problems efficiently.

## Topics

- linear search
- binary search
- selection sort
- bubble sort
- insertion sort
- recursion basics
- complexity analysis

## Practice questions

1. Search for a value in a list.
2. Sort numbers using selection sort.
3. Perform binary search on a sorted list.
4. Count the number of comparisons in a simple sort.
5. Explain the difference between O(n) and O(log n).

## Challenge questions

- Find duplicates in a sorted list.
- Compare insertion sort and selection sort.
- Solve a recursion-based countdown problem.

## Tips

- Learn the idea before memorizing code.
- Practice explaining time complexity in plain English.
