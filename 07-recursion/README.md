# 07. Recursion

This section introduces recursive thinking.

## Topics

- base case
- recursive call
- call stack
- factorial recursion
- fibonacci recursion
- backtracking basics

## Practice questions

1. Write a recursive function to print numbers from 1 to n.
2. Calculate factorial with recursion.
3. Calculate Fibonacci numbers recursively.
4. Check if a string is a palindrome using recursion.
5. Find the sum of numbers in a list recursively.

## Challenge questions

- Solve recursion problems with a stack trace.
- Compare recursive and iterative solutions.

## Tips

- Always define the base case clearly.
- Be careful with infinite recursion.
- Use small examples to test your logic.
