# 08. Object-Oriented Programming

This section focuses on writing organized code using classes and objects.

## Topics

- classes and objects
- constructors
- attributes and methods
- encapsulation
- inheritance
- polymorphism

## Practice questions

1. Create a `Student` class with name and grade.
2. Create a `Car` class with methods like start and stop.
3. Create a `BankAccount` class with deposit and withdraw methods.
4. Build a `Person` class and a child `Student` class.
5. Write a small inventory system using classes.

## Challenge questions

- Create a library management system using classes.
- Model a shopping cart with product and customer objects.

## Tips

- Think in terms of responsibilities.
- Keep your classes simple and readable.
- Use object relationships carefully.
