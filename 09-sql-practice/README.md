# 09. SQL Practice

This section focuses on learning SQL through practical exercises.

## Topics

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- JOIN
- aggregation
- CRUD operations

## Practice questions

1. Select all rows from a table.
2. Find all students with grades above 80.
3. Sort students by name.
4. Count how many students are in each class.
5. Join two tables on a common key.

## Challenge questions

- Retrieve all products in a category.
- Find the highest salary in a company table.
- Write a query to join orders and customers.

## Tips

- Understand table relationships.
- Try to use simple queries first.
- Always verify returned data carefully.
