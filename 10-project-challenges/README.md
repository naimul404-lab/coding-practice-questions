# 10. Project Challenges

This section combines multiple topics into complete mini-projects.

## Beginner challenges

- calculator app
- todo app
- student manager
- simple quiz
- contact book

## Intermediate challenges

- library system
- inventory manager
- expense tracker
- blog with notes
- product store app

## Advanced challenges

- student records with database
- task manager with login system
- API-based app
- mini social app
- e-commerce flow

## Project workflow

1. Understand the problem clearly.
2. Write a plan.
3. Break it into features.
4. Build the main logic first.
5. Improve design and readability.
6. Test with sample data.

## Tips

- Build small projects often.
- Do not aim for complexity too early.
- Improve one feature at a time.
